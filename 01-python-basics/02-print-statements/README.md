# Print Statements

## Objective

Learn how to display text, numbers, and calculations using Python.

## Concepts

- Strings: Text inside quotation marks.
- Integers: Whole numbers without quotation marks.
- Expressions: Python can calculate mathematical expressions.

## Code

```python
print("Python")
print(100)
print(50 + 50)

print("50 + 50")
print("2026")
```

## Output

```text
Python
100
100
50 + 50
2026
```

## What I Learned

- Display text using print().
- Display numbers without quotation marks.
- Perform calculations inside print().
- Understand the difference between strings and numbers.
