# Data Types

## Objective

Learn about four basic Python data types and how to check them using `type()`.

## Data Types

- `str`: Stores text, such as `"Python"`.
- `int`: Stores whole numbers, such as `2026`.
- `float`: Stores decimal numbers, such as `49.99`.
- `bool`: Stores either `True` or `False`.

## Code

```python
language = "Python"
year = 2026
price = 49.99
is_learning = True

print(type(language))
print(type(year))
print(type(price))
print(type(is_learning))
```

## Output

```text
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
```

## What I Learned

- Understand the difference between four basic data types.
- Identify strings, integers, floats, and Booleans.
- Use `type()` to check the data type of a variable.
- Understand that quotation marks make text a string.
- Recognize `True` and `False` as Boolean values.
