# Conditions

## Objective

Learn how to control program decisions using Python conditions.

## Concepts

- `if` statements
- `elif` statements
- `else` statements
- Nested if statements
- Multiple independent if statements
- Conditions with user input
- Indentation

## Code

See `main.py` for examples and practice programs.

## What I Learned

- Check conditions using comparison operators.
- Execute code when a condition is true.
- Use else when a condition is false.
- Check multiple conditions with elif.
- Build nested conditions.
- Create a grading system using conditions.
