# Variables

## Objective

Learn how to create variables and store values in Python.

## Concepts

- Variables store values using names.
- Use `=` to assign a value.
- Text values are written inside quotation marks.
- Variables can be reused in print statements.

## Code

```python
language = "Python"
print(language)

year = 2026
print(year)

name = "Ali"
goal = "AI Engineer"

print("My name is", name, "and I want to become an", goal + ".")
```

## Output

```text
Python
2026
My name is Ali and I want to become an AI Engineer.
```
