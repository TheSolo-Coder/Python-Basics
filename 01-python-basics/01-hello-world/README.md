# Hello World

## Objective

Write and run a first Python program.

## Concept

The `print()` function displays information in the output.

## Code

```python
print("Hello, World!")
print("I am learning Python.")
print("My AI engineering journey starts here.")
```

## Output

```text
Hello, World!
I am learning Python.
My AI engineering journey starts here.
```

## What I Learned

- Use `print()` to display text.
- Put text inside quotation marks.
- Run multiple print statements in one program.
